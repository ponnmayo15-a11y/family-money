# 親のお金一覧の調整

family-money の画面や項目を、ユーザーの「こうしたい」に合わせて直す。

## 使う場面

- ユーザーが「項目を足して」「画面を変えて」と言ったとき

## 実行手順

1. いまの範囲を確認する（CLAUDE.md のやること / やらないこと）
2. 1つの変更だけ入れる
3. `npm start` で画面が開くことを確認する
4. 何を変えたかを平易な日本語で伝える

## 基本姿勢

- 最初は最小限。複雑になりそうなら「シンプルにするとこうなります」と代替案を出す
- 空欄はゼロ扱いにしない
- 数字は円で表示する
- 関数は短く、冒頭に日本語コメントを書く
